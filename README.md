# Personal Portfolio Website

A modern and responsive personal portfolio website showcasing my skills, projects, and contact information.

## About

This portfolio website was built to present my work, technical skills, and achievements in a clean and professional way. It serves as my online presence for recruiters, collaborators, and potential clients.

## Features

- Responsive design for all devices
- Modern and clean user interface
- About Me section
- Skills showcase
- Projects section
- Contact section
- Smooth navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```
portfolio/
│
├── index.html
├── style.css
├── script.js
└── assets/
```

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/palakthakur07/portfolio.git
```

2. Open `index.html` in your browser.
